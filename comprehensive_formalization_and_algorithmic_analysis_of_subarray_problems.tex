\section{Introduction and Mathematical Preliminaries}
\label{sec:intro}

Contiguous subarray problems represent a foundational computational primitive in algorithm design, data structures, dynamic programming, and competitive programming platforms such as LeetCode. A central challenge in sequence processing is evaluating metrics---such as sum, product, parity, distinct element counts, minimums, maximums, or bitwise combinations---over bounded contiguous segments of an array.

While brute-force enumeration of all candidate subarrays requires quadratic $\mathcal{O}(N^2)$ candidate evaluations and $\mathcal{O}(N^3)$ naive computation time, optimal algorithms achieve linear $\mathcal{O}(N)$ or linearithmic $\mathcal{O}(N \log N)$ execution time by exploiting structural invariants, algebraic equivalences, monotonic state transitions, and memory-efficient data structures.

This research paper presents a formal, exhaustive, graduate-level taxonomy and algorithmic analysis of contiguous subarray problems. We establish six fundamental paradigms that completely govern the design of optimal subarray algorithms:
\begin{enumerate}
    \item \textbf{Prefix-Sum Space and Hash-Map Equivalence Classes (\S\ref{sec:prefix-hash}):} Decomposing contiguous subarray metrics into prefix state differences, enabling exact sum matching, divisibility classes, zero-sum optimizations, and domain transformations in $\mathcal{O}(N)$ time.
    \item \textbf{Sliding Window and Two-Pointer Search Space Pruning (\S\ref{sec:sliding-window}):} Exploiting monotonic contraction properties across non-negative domains to prune candidate states from $\mathcal{O}(N^2)$ to $\mathcal{O}(N)$, including exact-$K$ inclusion-exclusion decompositions and monotonic deque window bounds.
    \item \textbf{Dynamic Programming and Kadane's Local State Optimization (\S\ref{sec:dynamic-programming}):} Formalizing optimal sub-structure for maximum/minimum subarray sums, product propagation under multiplicative sign inversion, circular topology transformations, and single-element deletion DP models.
    \item \textbf{Monotonic Stack and Element Contribution Mechanics (\S\ref{sec:monotonic-stack}):} Inverting search focus from subarray iteration to element contribution, deriving exact left/right boundary ranges ($PSE$ and $NSE$) to evaluate sum of subarray minimums, maximums, and range bounds in $\mathcal{O}(N)$ time.
    \item \textbf{Divide-and-Conquer, Range Trees, and Monotonic Deques on Negative Prefixes (\S\ref{sec:divide-conquer}):} Resolving non-monotonic prefix spaces for range sum bounds ($\mathcal{O}(N \log N)$ merge-sort divide and conquer) and shortest target sums with negative numbers ($\mathcal{O}(N)$ monotonic deque on prefix sums).
    \item \textbf{Bitwise Monotonicity and Bounded State Transitions (\S\ref{sec:bitwise}):} Exploiting the 32-bit accumulation boundary of bitwise OR and AND operations to constrain distinct subarray bitwise states to $\mathcal{O}(30 N)$.
\end{enumerate}

Furthermore, we provide complete, compilable Java reference implementations for every canonical problem class, formal mathematical proofs of invariant correctness, and synthesize a diagnostic decision tree and taxonomy matrix (\S\ref{sec:taxonomy}) for immediate classification of any LeetCode subarray problem.

\subsection{Formal Definitions and Notation}

Let $A = [a_0, a_1, \dots, a_{N-1}]$ be a sequence of $N$ real or integer elements indexed from $0$ to $N-1$.

\begin{definition}[Contiguous Subarray]
A contiguous subarray $A[i \dots j]$ defined by start boundary $i$ and end boundary $j$ (where $0 \le i \le j < N$) is the ordered subsequence of elements:
\begin{equation}
A[i \dots j] = (a_i, a_{i+1}, \dots, a_j)
\end{equation}
\end{definition}

\begin{theorem}[Cardinality of Subarray Space]
The total number of non-empty contiguous subarrays in an array of size $N$ is exactly $\frac{N(N+1)}{2} = \mathcal{O}(N^2)$.
\end{theorem}
\begin{proof}
A contiguous subarray is uniquely identified by choosing a pair of indices $(i, j)$ such that $0 \le i \le j < N$. Summing the number of valid ending indices $j$ for each starting index $i$:
\begin{equation}
\sum_{i=0}^{N-1} (N - i) = N + (N-1) + \dots + 1 = \frac{N(N+1)}{2} = \frac{N^2 + N}{2} = \mathcal{O}(N^2)
\end{equation}
\end{proof}

\begin{definition}[Prefix Sum Array]
The prefix sum array $P$ of sequence $A$ is defined for $r \in [0, N-1]$ as:
\begin{equation}
P[r] = \sum_{k=0}^{r} a_k \quad \text{with base definition } P[-1] = 0
\end{equation}
\end{definition}

\begin{lemma}[Subarray Sum Decomposition]
The sum of elements in contiguous subarray $A[i \dots j]$, denoted $S(i, j)$, equals the difference of prefix sums:
\begin{equation}
S(i, j) = \sum_{k=i}^{j} a_k = P[j] - P[i-1] \quad \text{for } 0 \le i \le j < N
\end{equation}
\end{lemma}
\begin{proof}
Expanding prefix sums:
\begin{equation}
P[j] - P[i-1] = \sum_{k=0}^{j} a_k - \sum_{k=0}^{i-1} a_k = \sum_{k=i}^{j} a_k = S(i, j)
\end{equation}
\end{proof}

\section{Paradigm 1: Prefix-Sum Space and Hash-Map Equivalence Classes}
\label{sec:prefix-hash}

When an algorithm requires identifying subarrays whose sum matches a target $K$, equals zero, or satisfies a modulo divisibility condition $S(i, j) \pmod K = 0$, direct iteration yields $\mathcal{O}(N^2)$ time. By applying Lemma 1, target subarray conditions are mapped to prefix state algebraic equations solved via hash maps in $\mathcal{O}(N)$ time.

\subsection{Target Sum Matching ($P[j] - P[i-1] = K$)}

To find the count of subarrays with sum $K$, we rewrite $S(i, j) = K$ as:
\begin{equation}
P[j] - P[i-1] = K \iff P[i-1] = P[j] - K
\end{equation}
As we iterate $j$ from $0$ to $N-1$, $P[j]$ is computed in $\mathcal{O}(1)$. The number of valid left boundaries $i-1$ ending prior to $j$ equals the frequency of the value $(P[j] - K)$ observed in the prefix sequence up to $j-1$.

\subsubsection{Subarray Sum Equals K (LeetCode 560)}
We maintain a hash map storing the frequency of encountered prefix sums, initialized with $\{0 \to 1\}$ to account for $P[-1] = 0$.

\begin{theorem}[Completeness of Prefix Hash Map Search]
A single-pass iteration maintaining prefix sum frequencies correctly counts all valid subarrays summing to $K$ without overcounting or undercounting.
\end{theorem}
\begin{proof}
For any right index $j$, every valid subarray $A[i \dots j]$ with sum $K$ corresponds to a unique prior prefix index $i-1 < j$ where $P[i-1] = P[j] - K$. Because the hash map stores the exact count of indices $k < j$ where $P[k] = P[j] - K$, adding this count at step $j$ accounts for all valid subarrays ending at $j$. Summing over all $j \in [0, N-1]$ yields the total count of valid subarrays.
\end{proof}

\subsubsection{Longest Subarray Zero Sum (Screenshot Problem / Scaler / LeetCode)}
When the target sum is $K = 0$, the requirement simplifies to $P[i-1] = P[j]$. To maximize the subarray length $(j - i + 1) = j - (i - 1)$, we must find the \emph{earliest} index $i-1$ where $P[i-1] = P[j]$.

\begin{theorem}[Optimal Length Maximization Invariant]
To maximize subarray length for a target prefix sum match, the hash map must store strictly the \emph{first occurrence index} of each prefix sum value and never overwrite existing entries.
\end{theorem}
\begin{proof}
Let $idx_1 < idx_2$ be two indices where $P[idx_1] = P[idx_2] = V$. For a future index $j > idx_2$ where $P[j] = V$, the candidate subarray lengths are $L_1 = j - idx_1$ and $L_2 = j - idx_2$. Since $idx_1 < idx_2$, $L_1 > L_2$. Retaining $idx_1$ guarantees maximum length.
\end{proof}

\subsection{Modulo and Remainder Equivalence Classes ($S(i, j) \pmod K = 0$)}

For divisibility problems, $S(i, j) \pmod K = 0$ translates via prefix sums to:
\begin{equation}
(P[j] - P[i-1]) \pmod K = 0 \iff P[j] \pmod K = P[i-1] \pmod K
\end{equation}

\subsubsection{Canonical Negative Modulo Normalization}
In programming languages such as Java or C++, the modulo operator `%` produces negative remainders for negative operands (e.g., `-7 % 5 = -2`). Because remainder equivalence classes require positive bucket indexing in $[0, K-1]$, remainders must be normalized:
\begin{equation}
R(P) = ((P \pmod K) + K) \pmod K
\end{equation}

\subsubsection{Continuous Subarray Sum (LeetCode 523)}
Given length constraint $\ge 2$, we store the first occurrence index of remainder $R$. If $R$ was previously seen at index $firstIdx$ and $j - firstIdx \ge 2$, a valid continuous subarray of length $\ge 2$ exists.

\subsection{Domain Transformation: Equal 0s and 1s \& Parity Matching}

\subsubsection{Contiguous Array (LeetCode 525)}
To find the longest subarray with equal numbers of $0$s and $1$s, transform sequence $A$ by mapping $0 \to -1$ and $1 \to 1$. An equal count of $0$s and $1$s becomes a sum of $0$. The problem reduces directly to the Longest Subarray Zero Sum algorithm.

\subsubsection{Subarrays with Odd Sum (LeetCode 1524)}
Parity arithmetic dictates:
\begin{equation}
\text{Odd} - \text{Even} = \text{Odd} \quad \text{and} \quad \text{Even} - \text{Odd} = \text{Odd}
\end{equation}
If current prefix sum $P[j]$ is odd, any prior even prefix sum forms an odd subarray. If $P[j]$ is even, any prior odd prefix sum forms an odd subarray. We maintain scalar counts $odd\_cnt$ and $even\_cnt$, achieving $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
import java.util.HashMap;
import java.util.Map;

public class PrefixSubarraySolutions {

    // 1. Longest Subarray with Zero Sum
    public static int longestSubarrayZeroSum(int[] A) {
        Map<Long, Integer> firstSeen = new HashMap<>();
        firstSeen.put(0L, -1); // Base case for prefix sum 0 at index -1
        long pref = 0;
        int maxLen = 0;
        
        for (int j = 0; j < A.length; j++) {
            pref += A[j];
            if (firstSeen.containsKey(pref)) {
                maxLen = Math.max(maxLen, j - firstSeen.get(pref));
            } else {
                firstSeen.put(pref, j);
            }
        }
        return maxLen;
    }

    // 2. Subarray Sum Equals K (LeetCode 560)
    public static int subarraySumEqualsK(int[] A, int K) {
        Map<Long, Integer> freq = new HashMap<>();
        freq.put(0L, 1);
        long pref = 0;
        int count = 0;
        
        for (int x : A) {
            pref += x;
            if (freq.containsKey(pref - K)) {
                count += freq.get(pref - K);
            }
            freq.put(pref, freq.getOrDefault(pref, 0) + 1);
        }
        return count;
    }

    // 3. Subarray Sums Divisible by K (LeetCode 974)
    public static int subarraysDivByK(int[] A, int K) {
        Map<Integer, Integer> remFreq = new HashMap<>();
        remFreq.put(0, 1);
        long pref = 0;
        int count = 0;
        
        for (int x : A) {
            pref += x;
            int rem = (int) ((pref % K + K) % K); // Normalized positive remainder
            if (remFreq.containsKey(rem)) {
                count += remFreq.get(rem);
            }
            remFreq.put(rem, remFreq.getOrDefault(rem, 0) + 1);
        }
        return count;
    }

    // 4. Contiguous Array - Equal 0s and 1s (LeetCode 525)
    public static int findMaxLengthEqual01(int[] nums) {
        Map<Integer, Integer> firstSeen = new HashMap<>();
        firstSeen.put(0, -1);
        int pref = 0;
        int maxLen = 0;
        
        for (int j = 0; j < nums.length; j++) {
            pref += (nums[j] == 1) ? 1 : -1;
            if (firstSeen.containsKey(pref)) {
                maxLen = Math.max(maxLen, j - firstSeen.get(pref));
            } else {
                firstSeen.put(pref, j);
            }
        }
        return maxLen;
    }
}
\end{verbatim}

\section{Paradigm 2: Sliding Window and Two-Pointer Search Space Pruning}
\label{sec:sliding-window}

When sequence elements are strictly non-negative ($a_k \ge 0$), the prefix sum sequence $P[j]$ is monotonically non-decreasing ($P[j] \ge P[j-1]$). Expanding the right boundary $R$ increases window sum and distinct element counts, while advancing the left boundary $L$ decreases window metrics. This monotonicity enables two-pointer search space pruning from $\mathcal{O}(N^2)$ to amortized $\mathcal{O}(N)$.

\subsection{Variable Window Contraction Mechanics}

\subsubsection{Minimum Size Subarray Sum (LeetCode 209)}
We maintain window $[L, R]$. For each $R$, we add $A[R]$ to $window\_sum$. While $window\_sum \ge Target$, we update $min\_len = \min(min\_len, R - L + 1)$ and contract $L$ by subtracting $A[L]$.

\begin{theorem}[Amortized Linear Complexity of Sliding Window]
The two-pointer sliding window algorithm executes in $\mathcal{O}(N)$ total time complexity and $\mathcal{O}(1)$ auxiliary space.
\end{theorem}
\begin{proof}
The right pointer $R$ increments from $0$ to $N-1$ exactly $N$ times. The left pointer $L$ increments monotonically from $0$ to $N-1$ and never decrements. Across the entire execution, $L$ is incremented at most $N$ times. Total pointer movements are bounded by $2N = \mathcal{O}(N)$.
\end{proof}

\subsubsection{Subarray Product Less Than K (LeetCode 713)}
For positive integer arrays, expanding $R$ multiplies $prod$ by $A[R]$. While $prod \ge K$, we divide $prod$ by $A[L]$ and advance $L$.
\begin{lemma}[Ending-At Count Invariant]
For a valid window $[L, R]$ where all sub-windows ending at $R$ satisfy the condition, the number of valid contiguous subarrays ending strictly at $R$ is exactly $R - L + 1$.
\end{lemma}
\begin{proof}
The valid subarrays ending at $R$ are $A[R \dots R], A[R-1 \dots R], \dots, A[L \dots R]$. The starting indices range from $L$ to $R$, giving $(R - L + 1)$ distinct choices.
\end{proof}

\subsection{Exact-K Inclusion-Exclusion Decomposition}

\subsubsection{Subarrays with K Different Integers (LeetCode 992)}
Direct sliding window cannot maintain "Exactly $K$ distinct elements" because contracting $L$ when distinct elements equal $K$ might miss valid subarrays starting further right.

\begin{theorem}[Exact-K Decomposition Theorem]
Let $f(K)$ be the number of contiguous subarrays containing \emph{at most} $K$ distinct integers. The number of subarrays containing \emph{exactly} $K$ distinct integers is:
\begin{equation}
\text{Exactly}(K) = f(K) - f(K - 1)
\end{equation}
\end{theorem}
\begin{proof}
Let $\mathcal{S}$ be the set of all subarrays. Let $\mathcal{D}(s)$ be the number of distinct integers in subarray $s$. $f(K) = |\{s \in \mathcal{S} \mid \mathcal{D}(s) \le K\}|$. Partitioning this set:
\begin{equation}
\{s \mid \mathcal{D}(s) \le K\} = \{s \mid \mathcal{D}(s) \le K - 1\} \cup \{s \mid \mathcal{D}(s) = K\}
\end{equation}
Since these sets are disjoint:
\begin{equation}
f(K) = f(K-1) + \text{Exactly}(K) \implies \text{Exactly}(K) = f(K) - f(K-1)
\end{equation}
Because $f(K)$ enforces a monotonic "at most" condition, $f(K)$ is solved in $\mathcal{O}(N)$ time using a standard sliding window.
\end{proof}

\subsection{Sliding Window with Monotonic Double-Ended Queues}

\subsubsection{Longest Subarray with Absolute Difference $\le$ Limit (LeetCode 1438)}
When the window property depends on dynamic maximum and minimum values ($\max_{L \le k \le R} A[k] - \min_{L \le k \le R} A[k] \le Limit$), updating min/max during $L$ contraction requires monotonic deques:
\begin{itemize}
    \item \textbf{Max Deque:} Stores elements in monotonically decreasing order. $max\_dq.peekFirst()$ provides the window maximum in $\mathcal{O}(1)$.
    \item \textbf{Min Deque:} Stores elements in monotonically increasing order. $min\_dq.peekFirst()$ provides the window minimum in $\mathcal{O}(1)$.
\end{itemize}
When window violation occurs ($max\_dq.peekFirst() - min\_dq.peekFirst() > Limit$), $L$ advances, popping $A[L]$ from deques if matched.

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

public class SlidingWindowSubarraySolutions {

    // 1. Minimum Size Subarray Sum (LeetCode 209)
    public static int minSubArrayLen(int target, int[] nums) {
        int L = 0, sum = 0, minLen = Integer.MAX_VALUE;
        for (int R = 0; R < nums.length; R++) {
            sum += nums[R];
            while (sum >= target) {
                minLen = Math.min(minLen, R - L + 1);
                sum -= nums[L++];
            }
        }
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }

    // 2. Subarrays with K Different Integers (LeetCode 992)
    public static int subarraysWithKDistinct(int[] nums, int k) {
        return atMostKDistinct(nums, k) - atMostKDistinct(nums, k - 1);
    }

    private static int atMostKDistinct(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        int L = 0, count = 0;
        for (int R = 0; R < nums.length; R++) {
            freq.put(nums[R], freq.getOrDefault(nums[R], 0) + 1);
            while (freq.size() > k) {
                freq.put(nums[L], freq.get(nums[L]) - 1);
                if (freq.get(nums[L]) == 0) freq.remove(nums[L]);
                L++;
            }
            count += (R - L + 1); // Lemma 2 ending-at count invariant
        }
        return count;
    }

    // 3. Longest Subarray with Diff <= Limit (LeetCode 1438)
    public static int longestSubarrayDiffLimit(int[] nums, int limit) {
        Deque<Integer> maxDq = new ArrayDeque<>();
        Deque<Integer> minDq = new ArrayDeque<>();
        int L = 0, maxLen = 0;

        for (int R = 0; R < nums.length; R++) {
            while (!maxDq.isEmpty() && maxDq.peekLast() < nums[R]) maxDq.pollLast();
            while (!minDq.isEmpty() && minDq.peekLast() > nums[R]) minDq.pollLast();
            maxDq.addLast(nums[R]);
            minDq.addLast(nums[R]);

            while (maxDq.peekFirst() - minDq.peekFirst() > limit) {
                if (maxDq.peekFirst() == nums[L]) maxDq.pollFirst();
                if (minDq.peekFirst() == nums[L]) minDq.pollFirst();
                L++;
            }
            maxLen = Math.max(maxLen, R - L + 1);
        }
        return maxLen;
    }
}
\end{verbatim}

\section{Paradigm 3: Dynamic Programming and Kadane's Local State Optimization}
\label{sec:dynamic-programming}

When evaluating maximum, minimum, or product optimizations over subarrays where elements may be negative, greedy sliding window invariants fail because prefix sums are non-monotonic. Dynamic programming constructs state transitions over contiguous local choices.

\subsection{Classic Kadane's Algorithm (LeetCode 53)}

\subsubsection{State Definition and Recurrence}
Let $DP[i]$ be the maximum subarray sum ending strictly at index $i$. Any contiguous subarray ending at index $i$ either:
\begin{enumerate}
    \item Consists solely of element $a_i$.
    \item Extends the optimal contiguous subarray ending at index $i-1$ by appending $a_i$.
\end{enumerate}
This yields the Bellman recurrence relation:
\begin{equation}
DP[i] = \max(a_i, DP[i-1] + a_i)
\end{equation}
The global maximum subarray sum is $S^* = \max_{0 \le i < N} DP[i]$.

\begin{theorem}[Inductive Correctness of Kadane's Recurrence]
Kadane's recurrence correctly computes the maximum sum of any contiguous subarray ending at index $i$.
\end{theorem}
\begin{proof}
By induction on $i$:
\begin{itemize}
    \item \textbf{Base Case ($i=0$):} The only subarray ending at index $0$ is $A[0\dots 0]$, with sum $a_0$. $DP[0] = a_0$.
    \item \textbf{Inductive Step:} Assume $DP[i-1]$ is the optimal maximum sum for all contiguous subarrays ending at $i-1$. Any subarray ending at $i$ has form $A[k \dots i]$ for $0 \le k \le i$. If $k = i$, sum is $a_i$. If $k < i$, sum is $S(k, i-1) + a_i$. Maximizing over $k < i$ yields $(\max_{k < i} S(k, i-1)) + a_i = DP[i-1] + a_i$. Taking $\max(a_i, DP[i-1] + a_i)$ guarantees exact optimality for $DP[i]$.
\end{itemize}
\end{proof}

\subsubsection{Space Optimization}
Since $DP[i]$ depends only on $DP[i-1]$, auxiliary space reduces from $\mathcal{O}(N)$ array to scalar $current\_max$, achieving $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.

\subsection{Dual-State Propagation: Maximum Product Subarray (LeetCode 152)}

Multiplying numbers by a negative scalar inverts order inequalities ($x < y \implies -2x > -2y$). A large negative product becomes a large positive product when multiplied by another negative element.

\subsubsection{Dual Recurrence Equations}
We maintain two states simultaneously:
\begin{itemize}
    \item $MaxDP[i]$: Maximum product subarray ending at $i$.
    \item $MinDP[i]$: Minimum product subarray ending at $i$.
\end{itemize}

\begin{align}
MaxDP[i] &= \max\Big(a_i, \, a_i \cdot MaxDP[i-1], \, a_i \cdot MinDP[i-1]\Big) \\
MinDP[i] &= \min\Big(a_i, \, a_i \cdot MaxDP[i-1], \, a_i \cdot MinDP[i-1]\Big)
\end{align}

\subsection{Circular Topology Transformations (LeetCode 918)}

For a circular array where index $N-1$ connects to $0$, a maximum circular subarray takes one of two topological structures:
\begin{enumerate}
    \item \textbf{Non-Wrapping Subarray:} Standard linear Kadane maximum $KadaneMax(A)$.
    \item \textbf{Wrapping Subarray:} Extends from head and tail, leaving a contiguous middle subarray excluded. To maximize wrapping sum, we minimize the excluded middle subarray sum:
    \begin{equation}
    WrappingMax = TotalSum - KadaneMin(A)
    \end{equation}
\end{enumerate}

\begin{theorem}[Circular Subarray Edge Case Optimization]
If all elements in $A$ are negative, $KadaneMin(A) = TotalSum$, yielding $WrappingMax = 0$ (an empty subarray). In this scenario, the algorithm must return $KadaneMax(A)$.
\end{theorem}

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
public class DynamicProgrammingSubarraySolutions {

    // 1. Maximum Subarray Sum - Kadane's Algorithm (LeetCode 53)
    public static int maxSubArray(int[] nums) {
        int currentMax = nums[0];
        int globalMax = nums[0];
        
        for (int i = 1; i < nums.length; i++) {
            currentMax = Math.max(nums[i], currentMax + nums[i]);
            globalMax = Math.max(globalMax, currentMax);
        }
        return globalMax;
    }

    // 2. Maximum Product Subarray (LeetCode 152)
    public static int maxProduct(int[] nums) {
        int maxProd = nums[0];
        int minProd = nums[0];
        int globalMax = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            if (x < 0) { // Swap state bounds on negative factor
                int temp = maxProd;
                maxProd = minProd;
                minProd = temp;
            }
            maxProd = Math.max(x, x * maxProd);
            minProd = Math.min(x, x * minProd);
            globalMax = Math.max(globalMax, maxProd);
        }
        return globalMax;
    }

    // 3. Maximum Sum Circular Subarray (LeetCode 918)
    public static int maxSubarraySumCircular(int[] nums) {
        int totalSum = 0;
        int curMax = 0, globalMax = nums[0];
        int curMin = 0, globalMin = nums[0];

        for (int x : nums) {
            totalSum += x;
            curMax = Math.max(x, curMax + x);
            globalMax = Math.max(globalMax, curMax);
            
            curMin = Math.min(x, curMin + x);
            globalMin = Math.min(globalMin, curMin);
        }

        // Edge case: if all numbers are negative, globalMax is max single element
        if (globalMax < 0) return globalMax;
        return Math.max(globalMax, totalSum - globalMin);
    }
}
\end{verbatim}

\section{Paradigm 4: Monotonic Stack and Element Contribution Mechanics}
\label{sec:monotonic-stack}

Traditional brute-force algorithms iterate over all $\mathcal{O}(N^2)$ candidate subarrays and find the minimum/maximum element within each subarray. The \emph{Contribution Paradigm} flips this orientation: for each element $a_i$, we determine the exact count of contiguous subarrays in which $a_i$ serves as the minimum (or maximum) element.

\subsection{Range Boundary Determination ($PSE$ and $NSE$)}

For element $a_i$, define its maximum extension range $[L_i, R_i]$ where $a_i$ remains the minimum element:
\begin{itemize}
    \item \textbf{Previous Smaller Element ($PSE[i]$):} The largest index $l < i$ such that $a_l < a_i$. If no such element exists, $PSE[i] = -1$.
    \item \textbf{Next Smaller Element ($NSE[i]$):} The smallest index $r > i$ such that $a_r \le a_i$. If no such element exists, $NSE[i] = N$.
\end{itemize}

\begin{theorem}[Subarray Count via Boundaries]
The number of contiguous subarrays where $a_i$ is the minimum element is:
\begin{equation}
Count(i) = (i - PSE[i]) \times (NSE[i] - i)
\end{equation}
\end{theorem}
\begin{proof}
Any valid subarray $A[start \dots end]$ where $a_i$ is the minimum must have $start \in (PSE[i], i]$ and $end \in [i, NSE[i])$. The number of left boundary choices is $i - PSE[i]$, and right boundary choices is $NSE[i] - i$. Independence of boundary selection yields the product $(i - PSE[i]) \times (NSE[i] - i)$.
\end{proof}

\subsection{Duplicate Handling: Strict vs. Non-Strict Inequalities}

If array $A$ contains duplicate elements (e.g., $A = [2, 2]$), equal elements could be claimed as the minimum by multiple indices for the same subarray, causing overcounting.

\begin{theorem}[Asymmetric Boundary Uniqueness Theorem]
Defining $PSE$ using strict inequality ($a_l < a_i$) and $NSE$ using non-strict inequality ($a_r \le a_i$) guarantees that every contiguous subarray has exactly ONE unique designated minimum index.
\end{theorem}
\begin{proof}
Suppose a subarray contains multiple instances of the minimum value $V$ at indices $idx_1 < idx_2 < \dots < idx_k$.
Under non-strict $NSE$, $idx_1$ sees $idx_2$ as $a_{idx_2} \le a_{idx_1}$, so $NSE[idx_1] \le idx_2$. Thus $idx_1$'s right extension terminates before or at $idx_2$.
For $idx_2$, its $PSE$ search moves left; under strict $PSE$, it does not stop at $idx_1$ because $a_{idx_1} = a_{idx_2}$ is not strictly smaller. However, $idx_2$'s left bound includes $idx_1$.
Thus, only $idx_1$ claims subarrays containing both $idx_1$ and $idx_2$. Duplicate counting is mathematically eliminated.
\end{proof}

\subsection{Sum of Subarray Minimums \& Ranges (LeetCode 907 \& 2104)}

\subsubsection{Sum of Subarray Minimums (LeetCode 907)}
\begin{equation}
\text{Total Min Sum} = \sum_{i=0}^{N-1} a_i \times (i - PSE[i]) \times (NSE[i] - i) \pmod{10^9+7}
\end{equation}

\subsubsection{Sum of Subarray Ranges (LeetCode 2104)}
Range of subarray $A[i \dots j]$ is $\max(A[i\dots j]) - \min(A[i\dots j])$. Summing over all subarrays:
\begin{equation}
\sum_{\text{subarrays}} (\text{Max} - \text{Min}) = \sum_{i=0}^{N-1} a_i \cdot CountMax(i) - \sum_{i=0}^{N-1} a_i \cdot CountMin(i)
\end{equation}

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
import java.util.ArrayDeque;
import java.util.Deque;

public class MonotonicStackSubarraySolutions {

    // 1. Sum of Subarray Minimums (LeetCode 907)
    public static int sumSubarrayMins(int[] arr) {
        int N = arr.length;
        int[] pse = new int[N]; // Previous Smaller Element (Strict <)
        int[] nse = new int[N]; // Next Smaller Element (Non-strict <=)
        
        Deque<Integer> stack = new ArrayDeque<>();
        
        // Compute PSE
        for (int i = 0; i < N; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
                stack.pop();
            }
            pse[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }
        
        stack.clear();
        
        // Compute NSE
        for (int i = N - 1; i >= 0; i--) {
            while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
                stack.pop();
            }
            nse[i] = stack.isEmpty() ? N : stack.peek();
            stack.push(i);
        }
        
        long totalSum = 0;
        long MOD = 1_000_000_007;
        
        for (int i = 0; i < N; i++) {
            long leftCount = i - pse[i];
            long rightCount = nse[i] - i;
            long contribution = (leftCount * rightCount) % MOD;
            totalSum = (totalSum + contribution * arr[i]) % MOD;
        }
        
        return (int) totalSum;
    }

    // 2. Sum of Subarray Ranges (LeetCode 2104)
    public static long subArrayRanges(int[] nums) {
        return getContribution(nums, true) - getContribution(nums, false);
    }

    private static long getContribution(int[] nums, boolean isMax) {
        int N = nums.length;
        int[] left = new int[N];
        int[] right = new int[N];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < N; i++) {
            while (!stack.isEmpty() && (isMax ? nums[stack.peek()] <= nums[i] : nums[stack.peek()] >= nums[i])) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }

        stack.clear();

        for (int i = N - 1; i >= 0; i--) {
            while (!stack.isEmpty() && (isMax ? nums[stack.peek()] < nums[i] : nums[stack.peek()] > nums[i])) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? N : stack.peek();
            stack.push(i);
        }

        long sum = 0;
        for (int i = 0; i < N; i++) {
            long count = (long) (i - left[i]) * (right[i] - i);
            sum += count * nums[i];
        }
        return sum;
    }
}
\end{verbatim}

\section{Paradigm 5: Divide-and-Conquer, Range Trees, and Monotonic Deques on Negative Prefixes}
\label{sec:divide-conquer}

When subarray problem constraints break monotonicity and hash maps cannot answer range inequalities in $\mathcal{O}(1)$, advanced techniques such as Merge-Sort Divide and Conquer or Monotonic Deques on Prefix Sums are required.

\subsection{Count of Range Sums (LeetCode 327)}

\subsubsection{Problem Formalization}
Given lower and upper bounds, count subarrays satisfying $lower \le S(i, j) \le upper$. Via prefix sums:
\begin{equation}
lower \le P[j] - P[i-1] \le upper \iff P[j] - upper \le P[i-1] \le P[j] - lower
\end{equation}
Because this requires counting prefix values within range $[P[j] - upper, P[j] - lower]$, standard hash maps fail.

\subsubsection{Merge-Sort Divide and Conquer Algorithm}
We sort the prefix sum array $P$ recursively using merge sort. During the merge step between sorted left half $P[left \dots mid]$ and right half $P[mid+1 \dots right]$:
\begin{itemize}
    \item For each element $P[j]$ in the right half, valid left prefix sums $P[i]$ in the left half lie in range $[P[j] - upper, P[j] - lower]$.
    \item Because both halves are sorted, two pointers $k_1$ and $k_2$ in the left half move monotonically right as $j$ increases.
    \item Count of valid left prefixes for $j$ is $(k_2 - k_1)$ in $\mathcal{O}(1)$ amortized time per $j$.
\end{itemize}
Total time complexity is $\mathcal{O}(N \log N)$ and auxiliary space is $\mathcal{O}(N)$.

\subsection{Shortest Subarray with Sum at Least K (LeetCode 862)}

When array $A$ contains negative integers, prefix sum $P[j]$ is non-monotonic, preventing simple sliding windows.

\subsubsection{Monotonic Deque on Prefix Sums}
We maintain a deque of indices storing prefix sums $P[i]$ in strictly increasing order.
For each index $j$:
\begin{enumerate}
    \item \textbf{Target Condition Check:} While $P[j] - P[dq.peekFirst()] \ge K$, we record length $j - dq.peekFirst()$ and $dq.pollFirst()$.
    \begin{proof}[Proof of Popping First]
    Once $dq.peekFirst()$ satisfies the condition for index $j$, it will never produce a shorter valid subarray for any future index $j' > j$ (since $j' - dq.peekFirst() > j - dq.peekFirst()$). Discarding it is optimal.
    \end{proof}
    \item \textbf{Obsoletion Check:} While $P[j] \le P[dq.peekLast()]$, $dq.pollLast()$.
    \begin{proof}[Proof of Popping Last]
    $P[j]$ is smaller than $P[dq.peekLast()]$ AND located further right ($j > dq.peekLast()$). $P[j]$ is strictly superior as a starting point for future target sum subtractions and yields shorter subarray lengths. Thus $dq.peekLast()$ is dominated and can be safely purged.
    \end{proof}
\end{enumerate}
Total execution time is $\mathcal{O}(N)$ amortized.

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
import java.util.ArrayDeque;
import java.util.Deque;

public class AdvancedSubarraySolutions {

    // 1. Count of Range Sums (LeetCode 327) - O(N log N) Merge Sort
    public static int countRangeSum(int[] nums, int lower, int upper) {
        int N = nums.length;
        long[] pref = new long[N + 1];
        for (int i = 0; i < N; i++) pref[i + 1] = pref[i] + nums[i];
        return mergeSortAndCount(pref, 0, N + 1, lower, upper);
    }

    private static int mergeSortAndCount(long[] pref, int start, int end, int lower, int upper) {
        if (end - start <= 1) return 0;
        int mid = start + (end - start) / 2;
        int count = mergeSortAndCount(pref, start, mid, lower, upper)
                  + mergeSortAndCount(pref, mid, end, lower, upper);

        int k1 = start, k2 = start;
        for (int j = mid; j < end; j++) {
            while (k1 < mid && pref[j] - pref[k1] > upper) k1++;
            while (k2 < mid && pref[j] - pref[k2] >= lower) k2++;
            count += (k2 - k1);
        }

        // Standard Merge Step
        long[] sorted = new long[end - start];
        int i = start, j = mid, idx = 0;
        while (i < mid && j < end) {
            if (pref[i] <= pref[j]) sorted[idx++] = pref[i++];
            else sorted[idx++] = pref[j++];
        }
        while (i < mid) sorted[idx++] = pref[i++];
        while (j < end) sorted[idx++] = pref[j++];
        System.arraycopy(sorted, 0, pref, start, sorted.length);

        return count;
    }

    // 2. Shortest Subarray with Sum at Least K (LeetCode 862) - O(N) Deque
    public static int shortestSubarray(int[] nums, int k) {
        int N = nums.length;
        long[] P = new long[N + 1];
        for (int i = 0; i < N; i++) P[i + 1] = P[i] + nums[i];

        int minLen = N + 1;
        Deque<Integer> dq = new ArrayDeque<>();

        for (int j = 0; j <= N; j++) {
            while (!dq.isEmpty() && P[j] - P[dq.peekFirst()] >= k) {
                minLen = Math.min(minLen, j - dq.pollFirst());
            }
            while (!dq.isEmpty() && P[j] <= P[dq.peekLast()]) {
                dq.pollLast();
            }
            dq.addLast(j);
        }
        return minLen <= N ? minLen : -1;
    }
}
\end{verbatim}

\section{Paradigm 6: Bitwise Monotonicity and Bounded State Transitions}
\label{sec:bitwise}

Bitwise operations over contiguous subarrays exhibit monotonicity properties that drastically limit state complexity.

\subsection{Bitwise OR Monotonicity and Bounded Set Size (LeetCode 898)}

The bitwise OR operation is bit-accumulating: $A \text{ OR } B \ge A$. As window length increases, bits can only transition from $0 \to 1$ and never $1 \to 0$.

\begin{theorem}[30-Bit Monotonicity Bound]
In a 32-bit integer sequence, as left index $i$ moves from $j$ down to $0$, the cumulative bitwise OR value $A[i \dots j]$ can take at most 30 distinct values.
\end{theorem}
\begin{proof}
An integer has at most 30 value-bearing bits (excluding sign). Starting with $a_j$, extending leftwards can only set previously unset bit positions. Since set bits never clear, new distinct values occur only when at least one new bit is set to $1$. There are at most 30 available bits to set, bounding distinct OR values ending at $j$ to $\le 30$.
\end{proof}

\subsubsection{Algorithm and Complexity}
At step $j$, maintain a set $Cur$ of distinct OR values of subarrays ending at $j-1$. Compute $Next = \{ a_j \} \cup \{ x \text{ OR } a_j \mid x \in Cur \}$. Insert $Next$ into global set $Ans$. Since $|Next| \le 30$, overall time complexity is $\mathcal{O}(30 N)$ and space complexity is $\mathcal{O}(30 N)$.

\subsection{Subarray XOR Queries (LeetCode 1310)}

XOR satisfies self-inverse property ($x \oplus x = 0$). Subarray XOR is evaluated via prefix XOR array:
\begin{equation}
\text{SubarrayXOR}(i, j) = PrefixXOR[j] \oplus PrefixXOR[i-1]
\end{equation}
enabling $\mathcal{O}(1)$ query response after $\mathcal{O}(N)$ preprocessing.

\subsection{Compilable Java Reference Implementations}

\begin{verbatim}
import java.util.HashSet;
import java.util.Set;

public class BitwiseSubarraySolutions {

    // Bitwise ORs of Subarrays (LeetCode 898) - O(30 N)
    public static int subarrayBitwiseORs(int[] arr) {
        Set<Integer> ans = new HashSet<>();
        Set<Integer> cur = new HashSet<>();
        
        for (int x : arr) {
            Set<Integer> next = new HashSet<>();
            next.add(x);
            for (int y : cur) {
                next.add(y | x);
            }
            ans.addAll(next);
            cur = next;
        }
        return ans.size();
    }
}
\end{verbatim}

\subsection{Step-by-Step Problem Classification Algorithm}

When presented with any new contiguous subarray problem:
\begin{enumerate}
    \item \textbf{Check Monotonicity:} Are elements non-negative? If yes, apply \emph{Two-Pointer Sliding Window} (\S\ref{sec:sliding-window}).
    \item \textbf{Check Target Equality / Divisibility:} Is the objective finding a subarray sum equal to $K$ or divisible by $K$? Apply \emph{Prefix-Sum Hash Map} (\S\ref{sec:prefix-hash}).
    \item \textbf{Check Max / Min Local Optimality:} Is the objective maximizing sum/product under mixed positive/negative values? Apply \emph{Kadane Dynamic Programming} (\S\ref{sec:dynamic-programming}).
    \item \textbf{Check All-Subarray Aggregations:} Does the metric sum minimums, maximums, or ranges across all subarrays? Apply \emph{Monotonic Stack Contribution Paradigm} (\S\ref{sec:monotonic-stack}).
    \item \textbf{Check Negative Prefixes + Target Bounds:} Does the problem ask for range sums or shortest target sum with negative elements? Apply \emph{Merge Sort Divide and Conquer} or \emph{Monotonic Deque on Prefixes} (\S\ref{sec:divide-conquer}).
    \item \textbf{Check Bitwise Metrics:} Does the problem involve bitwise OR or AND? Apply \emph{30-Bit Monotonic Accumulation} (\S\ref{sec:bitwise}).
\end{enumerate}

By adhering to this unified mathematical framework and algorithmic classification, all contiguous subarray problems across LeetCode and advanced competitive programming can be systematically solved with optimal asymptotic time and space bounds.
